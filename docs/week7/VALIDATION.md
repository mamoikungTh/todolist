|---|---|
| Dataset | 12 Story: Todo 7 + Study 5; ID ไม่ซ้ำ |
| คะแนน/วัน Done | สอดคล้องกับ Remaining ทุก D0–D5 ของกราฟ Week 6 ทั้งสองชุด |

ทดสอบ workbook ผ่าน Artifact Tool ไม่ได้เปิด Microsoft Excel desktop ในสภาพแวดล้อมนี้ จึงไม่อ้างว่าทดสอบแอป Excel ทุกเวอร์ชันแล้ว วันที่จริงควรกรอกเป็น Date และใช้หน่วยเวลาเดียวกันทั้งชุด

## ขอบเขตการตรวจ

รอบนี้เพิ่มเอกสาร ข้อมูล กราฟ และ workbook ไม่มีการแก้โค้ด Todo/Study Planner จึงไม่อ้างว่าได้รัน unit tests ของแอปใหม่ในรอบ Week 7 ผล 63 tests ของ Week 6 ยังอยู่ใน [เอกสารเดิม](../week6/VALIDATION.md)

Excel เตรียมให้กรอก 12 รายการเดิมและใช้จำนวนเต็ม Story Points 0–100 ตาม validation สำหรับงานแลบ วันที่ปิด Sprint ต้องตรงกับ Sprint ที่รายงาน ถ้าเพิ่มรายการให้ขยายสูตร/validation/ช่วง Summary พร้อมกัน ไม่คัดลอกค่าตัวอย่างเป็นข้อมูลจริง

สูตรช่วยตรวจข้อมูลไม่ครบและลำดับวัน แต่ไม่ได้ตรวจว่าลิงก์ Evidence เป็นหลักฐานจริงหรือข้อความอ้างอิงถูกต้อง ทีมและผู้ตรวจต้องเปิดหลักฐานเพื่อตัดสิน DoD ก่อนกรอก Done
