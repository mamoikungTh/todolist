## 3. คำอธิบายแหล่งข้อมูล 4 บรรทัด

1. ชื่อ Story, คะแนนตัวอย่าง และวัน Done ตัวอย่างอ้างจาก Backlog/Burndown ของ Week 6 ที่มีป้ายจำลองอยู่แล้ว
2. วัน Request และ Start ยังไม่มีหลักฐาน จึงกำหนดเป็นตัวอย่างเพื่อแสดงวิธีคำนวณ โดยไม่ใช้วัน commit มาทดแทน
3. แหล่งยืนยันโค้ดคือ Git/PR และผล automated tests ส่วนสถานะ Done ของทีมต้องมีผล Manual Test และ Peer Review เพิ่ม
4. ก่อนส่งผลจริง ให้ใช้ Board, Daily, Review และชื่อผู้รับผิดชอบเติมชีต Actual พร้อมแนบหลักฐาน ถ้าหายไปให้เขียน Unknown หรือบอกช่วงประมาณพร้อมเหตุผล แยกออกจากค่าที่วัดได้

## 4. ตอบคำถามหลังกรอกข้อมูล

**ข้อมูลครบพอหรือยัง?** ครบสำหรับตัวอย่างคำนวณ แต่ยังไม่ครบสำหรับข้อสรุปจริงของกลุ่ม เพราะขาดวันงานและหลักฐาน DoD ห้ามรายงานว่า Velocity จริงเป็น 24 หรือ 15

**ทำไมบางงานไม่มี Start จริง?** ขณะนี้ไม่ทราบว่าเริ่มทันทีหรือไม่ได้อัปเดต Board ต้องตรวจบันทึกและถามเจ้าของงาน ไม่สามารถตัดสินจากช่องว่างอย่างเดียว

**มีงาน Done แต่ไม่มีหลักฐานหรือไม่?** ในตารางตัวอย่างกำหนด Done เพื่อคำนวณ แต่สถานะจริงยังไม่ยืนยัน แม้มีโค้ด/ภาพจาก automation ก็ยังไม่แทนหลักฐานที่ทีมต้องทำเอง

**มีงานที่คิดว่าเสร็จแต่ยังไม่ผ่าน DoD หรือไม่?** งานโค้ดพร้อม Demo หลายรายการยังรอผลตรวจจากนักศึกษา จึงควรใช้สถานะ “รอตรวจ” ใน Board จริง และยังไม่รวมคะแนนเป็น Done ของทีม
