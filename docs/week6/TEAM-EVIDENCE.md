## Submission Checklist

- [ ] 6-1: Backlog, กราฟจากข้อมูลจริงหรือได้รับอนุญาตให้ใช้จำลอง, วิเคราะห์ 5–10 บรรทัด, ปัญหา, วิดีโอ 3–5 นาที
- [ ] 6-2: Goal, Completed/Not Completed ตาม DoD, Live Demo, Feedback จริง ≥3, Updated Backlog, Reflection, วิดีโอ 5–10 นาที
- [ ] 6-3: Retro Board 3 ช่อง, ทุกคนพูด, Action ≥2 พร้อม Owner/วิธีวัด, วิดีโอ 5–10 นาที
- [ ] 6-4: Project/Goal/Backlog/Planning/Git, Daily ≥2, Burndown, Live Demo, Review/Retro/Reflection, ผลใช้ A1/A2, วิดีโอ 10–15 นาที
- [ ] กรอกชื่อสมาชิก วันจริง ผลทดสอบ และลิงก์วิดีโอครบ
- [ ] ผู้สอนเปิดลิงก์เอกสาร Git และวิดีโอได้
