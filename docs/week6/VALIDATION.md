## สิ่งที่ตรวจ

- วิชาซ้ำ/ข้อความว่าง, วันไม่มีจริง, วันอ่านหลังวันสอบ, ขอบเขตเวลา 5–480 นาทีและค่าทศนิยม
- เปลี่ยนวันสอบแล้วชนรอบอ่านเดิม, ป้องกันลบวิชาที่มีรอบอ่าน
- แก้ไขรอบอ่านโดยคงสถานะจบ, toggle กลับ, ยอดนาทีและจำนวนหลังลบ
- ค้นหาแบบไม่แยกตัวพิมพ์ + กรองวิชา + สถานะ + เรียงวัน, empty state
- refresh, schema ผิด/ID ซ้ำ/orphan, storage ถูกบล็อก, โหลดข้อมูลเสียโดยไม่เขียนทับ
- flow บน browser: CRUD, cancel/confirm, filter, corruption recovery และแจ้งเตือนเมื่อบันทึกไม่ได้

## ข้อจำกัดที่แสดงไว้ในโปรแกรม

ข้อมูลเฉพาะ browser, ไม่มีการ sync/บัญชี/แจ้งเตือน, เวลาที่แสดงเป็นเวลาของรอบที่วางแผน ไม่ใช่เวลาที่จับจริง, การล้างข้อมูล browser ทำให้แผนหาย ระบบยอมให้บันทึกแผนย้อนหลังเพื่อเก็บประวัติ แต่รอบอ่านต้องไม่เกินวันสอบของวิชา
